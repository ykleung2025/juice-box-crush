# 點解果汁盒會凹入去？

小學科學逐步動畫：密封果汁盒用吸管吸走空氣之後，點解會凹。

## 教學重點

當你用吸管吸走盒入面嘅果汁同空氣，而外面嘅空氣入唔到：

1. 盒入面氣體分子變少
2. 盒內氣壓下降
3. 盒外大氣壓力冇變，由外向內把紙盒壓凹

唔係「真空吸住」紙盒，係外面嘅大氣壓力推入來。如果空氣可以即時補充，紙盒就唔會凹。

## 點樣打開

- 本地：用瀏覽器打開 `index.html`（唔使安裝。檔案載入之後可以離線用，唔使網路，亦冇 API 金鑰）
- 網上課堂：<https://ykleung2025.github.io/juice-box-crush/>

撳「下一步」「吸一下」「再吸一下」逐格睇。可以「上一步」翻查，「重設」或者最後嘅「再睇一次」返到開頭。

## 示範步驟

1. 密封果汁盒 — 盒內、盒外同空氣分子
2. 兩邊差不多大 — 向內、向外嘅力箭嘴一樣長
3. 吸一下 — 分子同果汁沿吸管離開，數量減少
4. 再吸一下 — 盒內氣壓下降，入面箭嘴變弱、外面箭嘴仍然有力
5. 大氣壓力 — 叫出盒外向內推嘅力，四面八方都有箭嘴
6. 紙盒凹入 — 壓力差把盒壁壓凹，說明唔係真空吸住
7. 重溫 — 分子變少 → 盒內氣壓降低 → 大氣壓力把紙盒壓凹；如果空氣即時補充就唔會凹

## GitHub Pages

如果上面條網址未開到，喺 GitHub 儲存庫開啟 Pages（`main` 分支、根目錄）：

1. 打開儲存庫 **Settings**
2. 左邊揀 **Pages**
3. **Build and deployment** → **Source** 揀 **Deploy from a branch**
4. **Branch** 揀 `main`，資料夾揀 `/ (root)`
5. 按 **Save**

幾分鐘後就會出現喺 <https://ykleung2025.github.io/juice-box-crush/> 。

呢個網站係純靜態檔案（`index.html`、`styles.css`、`app.js`），唔使 build。

畫面用嘅字型係 [Noto Sans TC](https://fonts.google.com/noto/specimen/Noto+Sans+TC) 可變字重子集，授權見 `fonts/OFL.txt`。
